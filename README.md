# Suafruti • Cardápio Digital Oficial

Site de cardápio digital exclusivo e 100% responsivo (mobile-first) desenvolvido para a **Suafruti** (*"O melhor sabor da natureza."*), com pedidos diretos via WhatsApp e cálculo automático de taxa de entrega para Vitória - ES.

## Destaques do Projeto

- **Identidade Visual Exclusiva**: Paleta verde tropical inspirada na logo oficial da Suafruti, tipografia orgânica editorial (*Fraunces* + *Plus Jakarta Sans*) e fotos de estúdio otimizadas em WebP.
- **Pedido Rápido em 1 Toque ou Cesta Completa**:
  - **Pedir direto no card**: O cliente escolhe tamanho (`250 ml` ou `300 ml`), fruta única ou adicionais no próprio card e já é redirecionado para o WhatsApp com a mensagem montada.
  - **Cesta Inteligente**: Permite combinar vários itens, adicionar observações, retirar alguma fruta da base se desejar e calcular automaticamente o total com a taxa de entrega da região escolhida.
- **Cardápio Completo Configurado**:
  - **Salada de Frutas Tradicional**: `250 ml` (R$ 12,00) e `300 ml` (R$ 15,00) + 8 frutas (clicáveis direto no card para retirar caso não deseje alguma) + 6 opções de adicionais.
  - **Salada Overnight**: `250 ml` (R$ 18,00) e `300 ml` (R$ 20,00) + 8 frutas personalizáveis direto no card + 5 adicionais.
  - **Manga Temperada (Lançamento)**: `300 ml` (R$ 15,00) nos sabores **SUAFRUTI**, **Agridoce** e **Tropical** (com escolha entre páprica picante ou defumada).
  - **Fruta Cortada (Somente 1 opção)**: Morango, Manga ou Mamão — com troca dinâmica da foto do pote — `250 ml` (R$ 8,00) e `300 ml` (R$ 10,00).
  - **Caixa de Morango (Com 4 bandejas)**: Morango Médio (R$ 40,00) e Morango Graúdo (R$ 45,00).
- **Taxas de Entrega Configuradas**:
  - **Jesus de Nazareth**: Entrega Grátis
  - **Vitória**: R$ 3,00

## Como rodar localmente

```bash
npm install
npm run dev
```
